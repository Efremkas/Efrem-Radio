# Efrem Radio

Efrem Radio — приложение для прослушивания интернет-радиостанций с простым и современным интерфейсом.

## Возможности

- Прослушивание интернет-радиостанций
- Быстрое переключение между станциями
- Добавление радиостанций в избранное
- Регулировка громкости
- Отображение названия текущей станции
- Удобное управление воспроизведением
- Поддержка Windows

## Технологии

- C++
- Qt 6
- Qt Multimedia

## Назначение

Efrem Radio создано для удобного прослушивания радиостанций без необходимости открывать браузер или сторонние сервисы.
